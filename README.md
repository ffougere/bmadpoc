# Dossier Chat - POC Virtuel

## Objectif
Conserver les questions/reponses du chat et structurer les decisions du projet POC.

## Contenu
- 01-transcript-qa.md : journal des questions/reponses
- 02-decisions-et-hypotheses.md : hypotheses, decisions, cadrage
- 03-actions-et-livrables.md : livrables produits et statut
- 04-backlog-questions-ouvertes.md : points a instruire

## Sources projet utiles
- ../01-input.md
- ../02-synthese-executive-comite.md

## Convention de mise a jour
- Ajouter chaque nouvelle question en fin de 01-transcript-qa.md
- Capturer toute decision en fin de 02-decisions-et-hypotheses.md
- Mettre a jour les statuts dans 03-actions-et-livrables.md
- Fermer les points du backlog dans 04-backlog-questions-ouvertes.md
